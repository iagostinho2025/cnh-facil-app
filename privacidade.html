1. Termos de Uso

O aplicativo CNH Fácil é uma ferramenta educacional independente, sem vínculo oficial com Detran, Contran ou qualquer órgão de trânsito.

As questões são autorais e baseadas no Código de Trânsito Brasileiro (CTB). Não garantimos aprovação no exame teórico oficial. O desenvolvedor não se responsabiliza por reprovações ou custos decorrentes do uso deste aplicativo.

2. Política de Privacidade

Coleta de Dados

Este aplicativo NÃO coleta:

  • Dados pessoais (nome, CPF, e-mail, telefone)
  • Localização geográfica (GPS)
  • Informações de identificação do dispositivo

Armazenamento Local (LocalStorage)

O aplicativo utiliza LocalStorage do navegador para salvar:

  • Histórico de simulados (pontuações e datas)
  • Configurações de preferências

Esses dados ficam apenas no seu dispositivo e não são transmitidos para servidores externos.

Funcionamento Offline

Este é um Progressive Web App (PWA). Após o primeiro carregamento, funciona completamente offline, sem necessidade de conexão com a internet.

Compartilhamento de Dados

Nenhum dado é compartilhado com terceiros. O aplicativo não utiliza sistemas de rastreamento, análise ou publicidade.

3. Propriedade Intelectual

O código-fonte e as questões são de propriedade do desenvolvedor. Baseados na legislação brasileira de trânsito (domínio público).
